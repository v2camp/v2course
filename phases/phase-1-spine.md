# Phase 1 — Decide the Spine（确定主轴）

## 目标

把"这次到底要表达什么"压缩成清晰骨架。

## 必须明确的 6 个问题

1. **一句话主张是什么？**（核心判断或核心价值点）
2. **目标受众/对象是谁？**（学员、评审委员、面试官）
3. **主要解决什么焦虑、认知卡点或业务痛点？**
4. **这次不解决什么？**（明确边界）
5. **主叙事/逻辑线是什么？**
6. **最终目标（Impact/Action）是什么？**（如：转化后续课、通过晋升、拿 Offer）

### 系列实战课额外决策

- **是否包含"架构演进路线图"收口段？**（系列课推荐包含，单节课可选）
  - 包含时：需同步确认起点档（S几）、失败模式方向、后续档位对应课时
  - 不包含时：收口段用"行动清单"模式，不做演进
- **收口段模式选择**：
  - 行动清单收口（公开课/单节课）
  - 演进路线收口（系列实战课，推荐）：本课定位 → 3类失败模式 → 后续档位 → handoff
- **是否包含"附录深入思考题"？**
  - 实战课 = 默认是（4 道：3 架构题 + 1 深度题）
  - 录播课 = 可选（按课程定位决定）
  - 公开课/迷你课/面试辅导 = 默认否
  - 包含时：Phase 2 末尾需产出候选题卡片 → 用户选 4 道 → Phase 3 按规范写入附录
  - 方法论详见 `references/interview-questions.md`

## 主轴模板（根据类型调整）

- **课程类**：破题 -> 判断 -> 模型 -> 案例 -> 收口/承接
- **辅导类**：背景/挑战 -> 核心动作 -> 架构/模型 -> 成果/价值 -> 沉淀/思考

> **注意**：Phase 1 确定的主线结构是**本课型各产物共用的骨架**。实战课直接以它为起点展开讲义；公开课/录播课据此先产出大纲，再展开讲义与课程文档。因此主线结构必须清晰、稳定，不能在 Phase 3 随意增删章节。

## 本阶段产出（必须）

- `一句话主张`
- `目标对象定义`
- `主线结构`
- `边界说明`
- `价值落地/承接口径`
- `一句话反方质疑`（当前逻辑主轴最容易被挑战的点）
- `演进路线决策卡`（系列实战课，含起点档/收口模式/后续档位对应课时）
- `附录思考题决策卡`（含：是否包含 / 题数 / 题型配比 / 任何特殊要求）

> 以上文件存入 `.course/{task_name}/phase-1/`。
