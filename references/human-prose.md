# 活人感写作层（课程适配版）

> 来源：吸收 [KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing) 的材料纪律、说话位置、动作级禁令与改稿顺序，**按教学产物约束裁剪**。目标不是把课写成论坛长帖，而是让讲义/课程文档读起来像一个具体的人在认真讲清楚一件事。
>
> 与 `quality-guide.md` 分工：本文件管**中文怎么活**；`quality-guide.md` 管**教学产物底线**（角色边界、标签、标题命名、双端转换）。两者同时满足。

---

## 0. 规则优先级（多源冲突时）

1. 当前用户明确指定的文体、篇幅、产物类型（讲义 / 课程文档 / 架构书…）。
2. 事实、代码、评测与来源边界（课程侧更强，不可为「好读」编造）。
3. 课型产物规则（结构骨架、双端 1:1、附录、演进路线、代码索引）。
4. 本文件的散文默认写法与中文力学。
5. 改稿规则与检查脚本提醒（**只作用于初稿之后**）。

教学需要的清单、表格、定义句冒号、代码块**不受**散文禁令压制；但不得借教学之名堆姿势句。

## 1. 动笔前：材料门与说话位置

### 1.1 材料门（先于提纲与动笔）

作品靠什么站住，先于字数与结构：

- 用户/项目已提供的事实、数字、代码行为、评测结果、真实 bad case。
- 已核验的工业案例、产品流程、文档与源码。
- 可从当前工程复现的机制（类名、路径、阈值、失败形态）。

**不够就停或缩短，不靠下列手段撑篇幅**：抽象观点反复解释、无来源的「比如有一个人」、比喻同义改写、常识推演、把一点材料拆成用途/意义/风险/未来四段。

课程侧最低材料线（建议值，按课型标定）：

| 产物 | 建议至少托住正文的材料 |
|:---|:---|
| 单节讲义 / 课程文档 | ≥5 条可指认材料（代码事实 / 评测数字 / 真实失败 / 工业案例 / 用户动线），且能连成一条问题→方案链 |
| 架构类长文 | 每个核心决策 ≥1 处可核验佐证（代码、指标或公开案例） |

材料不够时的合法出口：研究补齐、向用户一次问清（最多 3 个问题）、缩小题目、缩短篇幅。**禁止**用重复解释和空洞升华补字数。

### 1.2 说话位置（内部回答，不交给用户）

1. 谁在讲这件事（讲师 / 资深工程师 / 技术作者），他凭什么知道，哪里只是推断。
2. 什么事情让人现在想讲（一个失败、一次上线、一个反直觉的数字）。
3. 手里哪些东西能托住（动作、数字、时间、原话、失败、代价、后来结果）。
4. 他对哪一点有明确判断，依据到哪为止。
5. 读者读完上一段，最自然会追问什么。

讲义允许「我/咱们」式讲师位置；课程文档收敛为技术作者位置，**声音来自取舍与依据，不来自代词堆砌**。

## 2. 第一稿：带着人写（正向目标为主）

第一稿从说话者与材料出发，像给一个聪明但不熟此题的人解释：边讲事情，边处理他下一步的疑问。**动笔阶段以正向写法为主**，硬禁令留到初稿完成后再清。

- 开头尽快碰到事情（一个失败、一个数字、一句真实对话），不要用「本文将从 N 个方面」预告全文。
- 段落标题用问题句 / 结论句 / 名词短语；**不要**用「两个成本、三层原因、四个阶段」代替文章（教学骨架除外，见 `templates.md`）。
- 一段只完成眼下一件事；**新段落必须新增**（事实、动作、例子、区别、后果）。同一观点换说法不算推进。
- 后一段接住前一段留下的问题；推进靠材料与因果，不靠「更深一层」「真正的关键是」。
- 主干先来：先出现谁做了什么，再补时间、条件、例子。
- 动作、数字、原话已经说明情绪或结论时就停，不追加解释。
- 允许正常的补充与自我修正；判断可以偏，但把依据放在附近。
- 讲完就停：不强行升华、不末段全文摘要；教学收口可以总结**要点表**，但不用空泛时代意义抬价。

校准句（few-shot，可跨域改写）：

> 先给动作、条件与风险：「他折腾了几年没挣到稳定的钱，老同事找过来问要不要一起做项目，他才换了方向。」
> 避免只剩姿势：「他关掉一条好走的路，把命运押上赌桌。」

## 3. 成稿后：动作级禁令（不是字面表）

> 禁的是**修辞动作**。换一套字继续做同一个动作，仍算命中。检查脚本只执行已写明的硬禁令。

### 3.1 课程正文硬禁令

- **不写翻案腔**：先立一个读者并没有的误解，再推翻它给下文抬价。已知外衣包括但不限于：「不是……而是……」「并非……而是……」「表面上……实际上……」「看似……实则……」「你以为……其实……」「说到底」「答案恰恰相反」「A 不重要，重要的是 B」。判断从正面下；只有材料真的走过「先前理解→被纠正」时才允许作者自纠，且不用固定句式。
- **不写三项以上同构排比**；两项为限，第三项换说法或删。
- **不给抽象名词配具体动词抒情**（时间不会「保管」细节，焦虑不会「显出形状」）。
- **不把动词名词化**（「完成了效率的提升」→「快了多少」）。
- **不写假具体**：无来源的精确时间、神态、天气、摆设、对白；假细节越具体，AI 味越重。
- **不写假深刻**：单独截图好看、放回正文却无新事实/解释/情绪的句子，大多删掉；连续短判断收尾只留最有材料的一处。
- **不用洞察路标**代替洞察：「值得注意的是」「需要指出的是」「更微妙的是」「还有一层」「从某种意义上说」。
- **不用「说白了」「说穿了」「先说结论」**当口头禅（教学收口给要点表是另一回事）。
- **非对象本身的借喻慎用**：仓库/抽屉/温度/死亡/坍塌/浪潮/钥匙/底座等包装抽象概念时删除；正在写这些东西时不受影响。
- **商业/模型黑话**不替普通事情抬价：赋能、抓手、闭环、护城河、颠覆、革命性、里程碑、在当今……时代。

### 3.2 教学语境放宽（显式允许）

| 形态 | 何时允许 |
|:---|:---|
| 冒号 | 引出定义、原话、列表、代码；**禁止**「核心是：」「一句话总结：」类提示性冒号 |
| 破折号 `——` | 偶用作补充；**禁止**电报式连排注释与「名词——结论」密集成段 |
| 列表 / 表格 | 教学导航、对照、速查、ADR；表前一句表后一句解读（见 `architecture-narrative` 病灶二） |
| 结构预告 | 课程路线图 / 骨架映射允许；正文小节仍须问题驱动，不能只填模板 |

### 3.3 词表残留（仍禁，作速查）

首先 / 其次 / 再次 / 综上所述；不可否认 / 扮演着不可或缺的角色；如前所述；具有里程碑意义的 / 革命性的；闭眼背诵、降维打击面试官等浮夸功利语。

替换倾向：工程口语（讲义）或平实技术句（课程文档），见 `quality-guide.md` §1.1 / §4.2。

## 4. 中文力学（读出声）

- **主干早点来**：圈出「……的，是……」「真正让……的」和一句多个「的」；先让人和动作出现。
- **前后指接**：后一句接前一句刚出现的人/物/动作；指代不清时把名字写回来。
- **停顿有轻重**：连续短句像敲桌子就合并；长句无落脚就拆开。普通段落普通地结束，勿每段金句收尾。
- **动作后少解释**：读者已能看见犹豫/失败/代价时，删掉追加说明；关键因果仍要说清。
- **段落高低差**：连续等长段检查是否同一模具；单句成段只留给确实要停的地方。

## 5. 改稿顺序（初稿之后才读）

目标：**先救人，再清句子**。保护已经活着的地方，再拆姿势。

1. **谁在说**：换一个模型也能原样写的段落优先处理；补信息来路与取舍，没有就删。
2. **有没有往前走**：标每段作用；同作用连续段合并；删只换说法的段落；压缩试验（删 1/3 体验几乎不变则保留短版）。
3. **拆表演性中文**：假深刻、假具体、假口语、抽象名词堆、比喻换场。
4. **中文顺不顺**：主干、指接、停顿、少解释、单双音节。
5. **清硬禁令**：§3.1 逐项；改违禁句时找回它想说的事实，用普通句子重说，**不要**换另一种漂亮句式。
6. **核事实/代码/引用**（课程必做）：类名路径阈值与来源。
7. **教学收口**：要点/衔接是否仍必要；避免空升华。

可选用脚本辅助硬禁令（若宿主提供了检查脚本）；脚本只执行已写明条目，不代替文体判断。

## 7. 不吸收进课程的部分（显式排除）

- 禁用一切冒号/破折号、禁清单与结构预告（教学需要）。
- 论坛腔表演（兄弟们、谢邀、烟头啤酒摆设）——活人感不靠服装。
- 为个人 IP 建立作者画像 / 个人规则库（本技能只服务当前教学产物）。
