# 适用与不适用场景

## 适用场景 (Applicable)

本 skill 适用于需要**深度策划、逻辑推演、价值叙事**的内容生产场景：

- **公开课**：侧重认知破题、表达张力和转化承接。
- **实战课**：侧重技术闭环、技能习得和作品沉淀。
- **迷你课**：侧重单点问题快速解决、精炼高效。
- **晋升辅导**：侧重架构能力表达、项目价值叙事、评审应对逻辑。
- **面试辅导**：侧重问题解决能力展示、职场画像构建、逻辑漏洞查杀。
- **深度技术文章**：需要建立核心模型、通过案例论证主张的长文。

## 不适用场景 (Non-applicable)

- **纯技术文档/API 引用**：仅描述参数、接口，无需叙事和逻辑推演。
- **README/Wiki**：仅用于说明如何安装、启动，不涉及教学或辅导。
- **纯措辞润色（不改结构/定位）**：建议走 SKILL.md §3 快速路径。
- **产品 Pitch Deck (融资用)**：融资路演有其特定的财务和市场模型，本 skill 侧重于能力与技术的教学/展示。

## 方法论骨架（速查）

### 0. 定位与挑战 (Phase 0)
- 明确：类型、目标、案例、形态、技术栈、系列课中的演进位置、命名规范。
- 任意技术领域均需完成领域适配声明（三域命名、S0-S4 映射、主要信源），参照 `references/domain-adaptation.md`。
- 动作：多方案对比、主动提出反对意见、拒绝过早收敛。

### 1. 核心骨架 (Phase 1)
- 提炼：一句话主张、逻辑主线、边界声明、落地目标、演进路线决策、附录思考题决策。

### 2. 证据/案例系统 (Phase 2)
- 双轨制：
  - **主讲述线/经验线**：承载张力、故事、亮点。
  - **事实支撑线/行业线**：承载确定性、边界、可信度（通过 agent-reach skill 调研）。
- **演进线证据（系列实战课）**：工业案例 ≤1.5 年新鲜度，必须有量化指标与来源。
- **深入思考题候选题（实战课）**：主路径 C（本课架构向上推演）+ 辅路径 A（架构文章反向提炼），8-10 张候选题卡片，用户选 4 道后进入 Phase 3。

### 3. 内容生产 (Phase 3)
- 模板化输出初稿。确保主张贯穿始终。
- 系列实战课中后期包含"架构启示与演进路线"收口段（四段式：当前坐标 → 失败模式 → 演进路线图 → 收口矩阵）。
- 实战课末尾包含"附录深入思考题"（4 道：3 架构题 + 1 深度题，附答题骨架 + 关联阅读，不给完整标准答案）。

### 4. 一致性校准 (Phase 4)
- L1-L4 分层对齐：产品体验/架构逻辑/工艺规范必须一致（含附录思考题数量/题型/格式对齐）；技术实现各自独立，不做类名级 1:1 翻译映射。
- 检查演示代码与文稿是否对齐，结论与论据是否匹配。

### 5. 专家审计 (Phase 5)
- 三视角（流量运营/最终学员/代码质量）+ 演进路线专项（系列实战课）+ 深入思考题专项（实战课 E1-E10）。
- 技术布道师（准确性）+ 表达教练（影响力）+ 代码审查员（地道性）三重专家评审。

## 快速路径适用场景

以下明确的局部修改场景可跳过部分阶段，直接进入对应环节：

- **仅润色已有讲义的措辞/去 AI 腔** → 直接进入 Phase 3 子集 + Phase 5 表达审查
- **仅补充/优化 SVG 图** → 直接进入 Phase 3 子集 + Phase 5 视觉审查
- **仅对齐/修复代码引用（应用架构课）** → 直接进入 Phase 5 视角 F 审查 + 修正
- **仅补充深入思考题** → 从 Phase 2 §C 开始

> **注意**：快速路径仅适用于明确的局部修改，完整课程制作仍必须走 6 阶段全流程。
