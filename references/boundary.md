# 适用与不适用场景

## 适用场景 (Applicable)

本 skill 适用于需要**深度策划、逻辑推演、价值叙事**的内容生产场景：

- **公开课**：侧重认知破题、表达张力和转化承接。
- **实战课**：侧重技术闭环、技能习得和作品沉淀。
- **迷你课**：侧重单点问题快速解决、精炼高效。
- **晋升辅导**：侧重架构能力表达、项目价值叙事、评审应对逻辑。
- **面试辅导**：侧重问题解决能力展示、职场画像构建、逻辑漏洞查杀。
- **深度技术文章**：需要建立核心模型、通过案例论证主张的长文。

## 不适用场景 (Non-applicable)

- **纯技术文档/API 引用**：仅描述参数、接口，无需叙事和逻辑推演。
- **README/Wiki**：仅用于说明如何安装、启动，不涉及教学或辅导。
- **局部润色**：仅修改措辞、修饰语，不涉及结构和定位调整。
- **产品 Pitch Deck (融资用)**：融资路演有其特定的财务和市场模型，本 skill 侧重于能力与技术的教学/展示。

## 方法论骨架（速查）

### 0. 定位与挑战 (Phase 0)
- 明确：类型、目标、案例、形态、技术栈、系列课中的演进位置、命名规范。
- 非 AI Agent 领域需完成领域适配声明（三域命名、S0-S4 映射、主要信源）。
- 动作：多方案对比、主动提出反对意见、拒绝过早收敛。

### 1. 核心骨架 (Phase 1)
- 提炼：一句话主张、逻辑主线、边界声明、落地目标。

### 2. 证据/案例系统 (Phase 2)
- 双轨制：
  - **主讲述线/经验线**：承载张力、故事、亮点。
  - **事实支撑线/行业线**：承载确定性、边界、可信度（通过 agent-reach skill 调研）。
- **演进线证据（系列实战课）**：工业案例 ≤1.5 年新鲜度，必须有量化指标与来源。

### 3. 内容生产 (Phase 3)
- 模板化输出初稿。确保主张贯穿始终。
- 系列实战课中后期包含"架构启示与演进路线"收口段（四段式：当前坐标 → 失败模式 → 演进路线图 → 收口矩阵）。

### 4. 一致性校准 (Phase 4)
- L1-L4 分层对齐：产品体验/架构逻辑/工艺规范必须一致；技术实现各自独立，不做类名级 1:1 翻译映射。
- 检查演示代码与文稿是否对齐，结论与论据是否匹配。

### 5. 专家审计 (Phase 5)
- 三视角（流量运营/最终学员/代码质量）+ 演进路线专项（系列实战课）。
- 技术布道师（准确性）+ 表达教练（影响力）+ 代码审查员（地道性）三重专家评审。
