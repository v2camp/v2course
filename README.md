# Course Skill

这是一个专为 AI Agent 打造的高级课程产品制作 Skill。它旨在指导 AI Agent 从 0 到 1 策划并制作高品质的各类课程与辅导材料（包括公开课、实战课、录播课、迷你课、晋升/面试辅导等），并支持多版本管理与双视角评估。录播课:与三节课等平台合作的线上课,1–8 小时、8–20 分钟章节;course-skill 管到脚本层(选题/大纲/讲义/PPT文稿/录制脚本),视频录制/剪辑留给人。

## 🌟 核心能力

- **Plan 驱动工作流**：强制进入计划模式，基于课程名称、版本和目标产物制定严密的 6 阶段产出计划。
- **多版本一致性管理**：支持 TS 版、Java 版等多语言版本的共性抽取与特性隔离。
- **企业级排版规范**：内置飞书等协作平台的 Markdown 兼容性规范（如表格对齐、特殊修饰符隔离）。
- **视觉资产升级**：强制将传统的 ASCII 文本图形升级为高质量的 SVG 矢量图，并独立文件存储。
- **去 AI 腔与拟真口语**：内置表达教练与技术布道师子 Agent，强制规避 AI 常用套话，使用资深架构师的工程口语。
- **代码质量把关**：内置代码审查专家子 Agent，支持 Java/TS 双语言，从编译正确性、配置一致性、测试覆盖、安全等 8 大维度审查教学代码质量。
- **三视角质量门禁**：产出后必须经过"流量运营视角"、"最终学员视角"、"代码质量视角"的严格审计。

## 🚀 如何使用

在支持 Agent Skill 的 IDE（如 Trae）中，当用户意图涉及“写讲义”、“做大纲”、“课程策划”时，Agent 会自动触发此 Skill。

你也可以通过显式指令调用：
```text
Use Skill: course-skill 帮我为《AI Agent 实战课》写一份大纲
```

## 🛠️ 核心规范速览

1. **过程文件隔离**：所有过程产物必须存放在项目根目录的 `.course/` 下，禁止污染正式课程目录;课程目录只放正式交付物。
2. **SVG 绝对隔离**：严禁在 Markdown 内部嵌入 SVG 代码，必须存入 `images/` 目录并使用相对路径引用。
3. **禁用角色卡片**：严禁使用 `[讲师侧记]`、`[学员踩坑警告]` 等包装卡片，一律使用平实的 **【要点】**、**【敲黑板】** 承载干货。
